List prices for 2026, published in February: arm with Gripper v1 $38,000; annual software and support $4,800 per arm; field install $2,500 per site. Volume tiers start at 20 arms.

| Item | List | 20+ arms | 50+ arms |
| --- | --- | --- | --- |
| Arm + Gripper v1 | $38,000 | $35,500 | $33,000 |
| Software + support / arm / yr | $4,800 | $4,500 | $4,200 |
| Premium support uplift | +20% | +20% | +15% |
| Field install / site | $2,500 | $2,500 | waived |

This sheet predates [[eng/gripper-v2|Gripper v2]] and has no v2 price or upgrade credit. List prices were set at the 38% margin target in the [[finance/operating-plan-2026|2026 Operating Plan]], before the [[finance/gross-margin-plan|Gross Margin Plan]] work started. Discounts from list are governed by [[sales/deal-desk-rules|Deal Desk Rules]].
